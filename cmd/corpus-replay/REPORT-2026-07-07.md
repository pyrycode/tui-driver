## Suspects worth a look

- **`mcp-failure` (95 prod-ok):** expected, not a forgery. The agent forks run
  with a deliberately-failing `github` MCP plugin as a canary, so the "1 MCP
  server failed" banner is real chrome. This is the harness correctly seeing true
  chrome, and a useful positive control that the banner detector fires.
- **`modal:slash-picker` (124 prod-ok, 61 e2e-ok):** the largest modal-class
  fire source in healthy runs. Worth confirming these are genuine picker frames
  (an on-screen `/`-row plus the highlight colour) and not syntax-highlighted
  output that happens to carry both signals. First follow-up candidate for the
  next detection pass; not filed, flagged here.
- **`unknown-dialog` (2 prod-err, 1 e2e-ok):** the #224 novel-dialog shape firing
  a handful of times, all in error or test runs — the class it was built to
  catch.

idle and thinking fire in essentially every run and are normal activity, not
suspects.
