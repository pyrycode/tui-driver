## Summary

`probe-cwd-encoding` ([#206](206.md)) sends a throwaway `"hi\r"` purely to make `claude` create its deferred session JSONL. On claude 2.1.199 it was firing that send on a **false idle**: `WaitUntil(IsIdle)` — the bare `❯` glyph appearing ~0.25s into startup, before claude's input handler is wired — fires while claude is still mid-render, so the keystroke is dropped, no JSONL appears, and the probe's internal 30s glob-poll times out ([#251](251.md) diagnosis; de-gated there via `NonGating: true`, not fixed).

This ticket replaces the two edge-triggered checks (`WaitUntil(IsIdle)` → `if HasTrustModal` → `SendKeys`) with a **level-triggered "settled" gate**: a target predicate must hold *and* the PTY must have emitted no new bytes for `settleWindow` (1s). The false idle is a transient produced *while claude is still rendering*; requiring quiescence waits past that render burst. Where a stronger signal exists, it's preferred over bare quiescence — a fresh temp cwd always shows claude's trust-folder dialog, so:

1. **Phase 1** waits for `settled(HasTrustModal)`, bounded by `trustModalWait = 15s` with a fallback to the quiescent-idle path if no modal appears (rare auto-trusted cwd).
2. **Phase 2** answers trust per policy — now reached only once the modal is genuinely settled, so `-trust-folder=fail` no longer races the false idle.
3. **Phase 3** waits for `settled(!HasTrustModal && IsIdle)`, then sends `"hi\r"`.

Quiescence is measured off the existing `Session.LastAppendAt()` clock — no new library surface, no `EncodeCwd` change, no `cmd/e2e-runner/main.go` edit (that's #264's job). The pure gate logic is extracted as `isSettled(want bool, sinceLastAppend, window time.Duration) bool`, table-tested (`TestIsSettled`) so the deterministic half of the design is confirmable in the claude-free `make check` gate. The `OBSERVED:` block gained a `readiness_signal=<trust-modal-settled|quiescent-idle-fallback> elapsed_to_ready=… settle_window=…` line plus per-phase stderr markers — the durable per-run evidence the operator needs to judge the 10-consecutive-runs bar (locked at exactly 10, any timeout resets the streak to zero).

## Patterns established

- **Semantic-anchor-with-quiescence-fallback, as a probe-local (not library) idiom.** `settledPredicate(s *Session, window time.Duration, want func([]byte) bool) func() bool` composes any existing screen predicate with a PTY-quiet requirement via `WaitUntil`. This is deliberately *not* promoted to `pkg/tuidriver` — #173 Open Q1 already established there's no in-library positive readiness signal that a claude-free gate can validate, so the pattern stays inside `cmd/probe-cwd-encoding/main.go` until (if ever) live evidence justifies lifting it. If a future ticket needs the same shape elsewhere, re-derive it locally first; don't reach for this file's helper as a library import.
- **Bounded fallback sub-context inside a wall-timeout-bound root.** Phase 1's `trustModalWait` is a `context.WithTimeout(rootCtx, trustModalWait)` — disambiguating "sub-timeout elapsed, fall back" from "wall timeout hit, fail" by checking `rootCtx.Err()` after the bounded `WaitUntil` returns (sub-timeout leaves the parent live; the wall timeout does not). Reusable shape for any probe that wants an optional fast-path anchor with a slower fallback, both under one overall deadline.

## Lessons learned

- **Re-anchoring is a `spike`, not a normal turn — and shipping the code is not the same as answering the question.** The AC1/AC4 vs. AC2/AC3 split (dev turn vs. operator-run live verification) is the load-bearing structure here; per [#165](165.md)/[#166](166.md) precedent, a fix gated on an unresolved live-claude empirical crux gets split spike-from-fix rather than speccing+shipping both branches. The negative finding (settle fires prematurely if claude wires input asynchronously during a PTY-quiet gap — see the spec's Open Question 1) is a real possible outcome, not a formality; this file will need an update once the operator's 10-run streak (or its failure) is recorded.
- **Code review flagged a non-blocking maintenance nicety, deferred to #264 rather than reworked here:** `settledPredicate` re-derives quiescence inline via `time.Since(s.LastAppendAt())` instead of calling the repo-wide idiom `Session.QuietFor()` (used by 5 sibling `spike-*` binaries), which carries a zero-value guard the inline form lacks. Functionally correct and matches the spec's verbatim formula — fold into `QuietFor()` when #264 touches this file next, don't treat as a standalone fix.
