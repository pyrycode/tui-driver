## Features

- [CastRecorder](features/cast-recorder.md) — `tuidriver.NewCastRecorder(w io.Writer, cols, rows int) *CastRecorder` since #125: an `io.Writer` flight recorder that mirrors a PTY byte stream to an asciinema v2 `.cast` (`WriteHeader()` emits the `{"version":2,"width","height"}` header line, each `Write(p)` appends one `[elapsed, "o", string(p)]` event); drops straight into `SpawnOpts.Mirror` (the passive mirror seam — previously only teed to `os.Stderr` — now has a library recording consumer; no `session.go` change); elapsed clock starts lazily on the first `Write` so the first event is ≈ 0 regardless of the setup→first-byte gap; data encoded `json.Marshal(string(p))` — valid UTF-8 round-trips byte-for-byte, invalid UTF-8 coerced to U+FFFD (accepted; no hand-rolled escaper); output-only (`"o"`), no redaction (raw verbatim bytes), `WriteHeader`/`Write` surface the underlying write error rather than swallow it; stdlib-only, single-writer contract with a defence-in-depth mutex; library-only — `PYRY_RECORD_DIR` file-creation/naming/permission wiring + the deferred `cmd/analyze-cast` offline analyzer live downstream (pyrycode#552)
- [Local-attach mirror surface](features/attach-mirror-surface.md) — two additive opt-in `Session` surfaces since [#136](codebase/136.md) for a local `pyry attach` head (mobile-remote-head Phase 5 / consumer ADR 025 open risk #1): `SpawnOpts.MirrorOutput bool` + `(*Session).MirrorOutput() <-chan []byte` stream a live receive-only feed of the hosted process's raw PTY output as opaque per-chunk copies — a **third tap** on the existing reader goroutine taken from the *live* read (before the parse-oriented rolling buffer, so no parse-able `io.Reader` over the buffer and no removed `Buffer`/`PTY`/`SpawnOpts.Mirror` seam reopened), `nil` when the opt-in is false; the reader is sole sender + sole closer, send is **non-blocking drop-newest** at `defaultMirrorOutputBuffer = 256` (deliberately diverges from `Events()`/`TailJSONL` block-on-full because this send rides the *shared* reader goroutine — blocking would freeze state detection and deadlock `Close`'s `<-readerDone`; under a drop policy buffer depth maps to dropped-frame frequency not stall duration, hence 256 over Events' 32; a dropped chunk heals on claude's next full repaint, "verbatim" = content-identical-when-delivered, not lossless), per-chunk `copy` defuses the reused-4 KB-`buf` aliasing, LIFO `defer close(mirrorOut)` after `defer close(readerDone)` guarantees a `Wait()`-then-drain observes the stream already closed; `(*Session).AttachInput(p []byte) error` is the paired production raw-input path over the internal `writeRaw`, a sibling to (not a rename of) the spike-only `SendKeys`; both directions documented **opaque-bytes-no-parse** (consumer must never inspect/match/branch on content — all screen knowledge stays inside tui-driver; `<-chan []byte` / `[]byte` shapes are hostile to tokenising) with a mandatory `SECURITY:` note on `MirrorOutput` (carries every byte claude renders incl. file contents + secrets — consumer owns transport confidentiality; drop path forbids logging chunk bytes) and the consumer owning attach-auth per ADR 025; no existing symbol changed signature, `SendKeys`/`RecordTo`/`MirrorStderr`/rolling buffer untouched; composes with `RecordTo` (the lossless file-owned sibling sink, [#125](codebase/125.md)); lives in `pkg/tuidriver/session.go` + `keys.go`
- [e2e harness](features/e2e-harness.md) — `make e2e` runs the in-process `claude-version-lock` check (asserts every `flag=` and `value=` pinned in `claude-version.lock` still appears in `claude --help`; the lock's `version=` is informational only since #64 — claude patch drift no longer gates the harness; short-circuits the rest of the run on flag/value drift) first, then every spike + probe + `snapshot-drift` serially against real `claude`, emitting `e2e-report.json` (pass/fail/timeout per check, single CI artifact); headless-MCP plumbing rides the `EnsureClaudeEnv` seam via `TUIDRIVER_STRICT_MCP_CONFIG=1`; `make e2e MODEL=haiku EFFORT=low` rides the same seam via `TUIDRIVER_CLAUDE_MODEL` / `TUIDRIVER_CLAUDE_EFFORT` to pin a cheap claude pair for CI (18–90× cheaper than the default Opus + high;
